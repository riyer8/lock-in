# The loop

**Choose → Plan → Act → Observe → Audit → Learn → Adapt**

That's the app, not a slogan. Here's how it shows up.

| Step | In the app |
| --- | --- |
| **Choose** | Onboarding identities, then [Goals](screens.md#goals). Who you're practicing. |
| **Plan** | [Today](screens.md#today). A few actions. |
| **Act** | Start on Today. Cues while Chrome is open. Skip with a reason if you have to. |
| **Observe** | Browser time (domains + duration only), check-ins, every complete/skip as an event. `EventStore` is the record. |
| **Audit** | [Audit](screens.md#audit). What happened vs what was planned. |
| **Learn** | Patterns from multiple days. Experiments exist as an engine; the result shows on Audit, not its own tab. |
| **Adapt** | Audit **Try this**. Tomorrow's plan changes. If the plan keeps failing, shrink it. Don't nag harder. |

What you *meant* to do is not the source of truth. What got written as an event is.

There is no Coach tab and no model call. Adaptation is local. Food is a goal area, not a meal log. Today currently shows up to three saved plan items even though the planner can do 3–5.
